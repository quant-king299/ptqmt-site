手续费计算
# 双向收取
```python
买入手续费 = 买入金额 × 0.0001 （万分之一）
卖出手续费 = 卖出金额 × 0.0001 （万分之一）

```
# 最低5元
手续费 = max(手续费, 5元)
滑点模拟
# 可配置滑点率
```python
买入滑点 = 当前价 × (1 + 滑点率)
卖出滑点 = 当前价 × (1 - 滑点率)

```
# 默认滑点率：0%（可调整）
整手交易
# A股买入必须是100股的整数倍
```python
买入股数 = int(买入金额 / 价格 / 100) × 100

```
# 卖出可以是任意数量（但要≤持仓）
```python
卖出股数 = min(计划卖出, 当前持仓)

```

### 5.3 性能计算
收益率计算
# 每日收益率
```python
日收益率 = (今日总资产 - 昨日总资产) / 昨日总资产

```
# 累计收益率
```python
累计收益率 = (最终总资产 - 初始资金) / 初始资金

```
# 年化收益率
年化收益率 = (1 + 累计收益率)^(365/回测天数) - 1
最大回撤计算
# 回撤 = (峰值 - 当前值) / 峰值
```python
回撤序列 = []
峰值 = 0

for 总资产 in 每日资产:
 if 总资产 > 峰值:
 峰值 = 总资产
 回撤 = (峰值 - 总资产) / 峰值
 回撤序列.append(回撤)

最大回撤 = max(回撤序列)
```

# 夏普比率 = (年化收益 - 无风险利率) / 年化波动率

## 💡 十、常见问题FAQ

### Q1: 这个平台免费吗？

**A**: 完全免费！开源项目，所有功能都可以使用。

唯一需要的是Tushare Token，但也可以只用DuckDB本地数据。

### Q2: 必须会编程吗？

**A**: 不需要！

使用内置策略：可视化配置，点击即可

自定义策略：需要Python基础

### Q3: 数据需要更新吗？

**A**: 需要定期更新（建议每月一次）

# 重新下载最新数据
python run_gui.py
→ 进入下载页面
→ 选择最新月份
→ 点击下载

### Q4: 可以实盘交易吗？

**A**: 目前只支持回测，实盘对接功能开发中。

### Q5: 为什么我的回测结果不一样？

**A**: 可能的原因：

数据时间范围不同

参数设置不同

数据源不同（DuckDB vs Tushare）

建议：使用相同的数据和参数，结果才会一致。
