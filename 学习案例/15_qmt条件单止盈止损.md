## 🚀 四重策略保护体系

本系统包含**4套互补策略**，从不同角度保护您的利润：

### 🥇 策略1：浮盈回落止损（首选核心）

**适用场景**：保护已有利润

**原理**：当浮盈达到目标区间后，跟踪最高价，从最高价回落超过设定比例时触发止损

**参数配置**：

最小浮盈：开始监控的盈利比例（如20%）

最大浮盈：达到后强制止盈（如50%）

回落止损：从最高价回落超过此比例时止损（如10%）

**示例**：成本价10元，涨到12元（浮盈20%）开始监控，最高涨到15元后回落到13.5元（回落10%），触发止损

### 🥈 策略2：最高价回落止损（次选核心）

**适用场景**：趋势行情保护

**原理**：持仓期间跟踪最高价，当最高价涨幅超过阈值后，监控回落幅度

**参数配置**：

涨幅阈值：最高价涨幅超过此值后开始监控（如10%）

回落止损：从最高价回落超过此比例时止损（如5%）

**示例**：成本价10元，最高涨到12元（涨幅20%）开始监控，回落到11.4元（回落5%），触发止损

### 🥉 策略3：高开回落止损（场景补充）

**适用场景**：高开快速止盈

**原理**：针对高开场景，当高开幅度达标且冲高后，监控回落幅度

**参数配置**：

高开：当日开盘价涨幅超过此值（如3%）

高于开盘：最高价高于开盘价的比例（如2%）

回落止损：从最高价回落超过此比例时止损（如2%）

**示例**：昨收10元，今开10.3元（高开3%），冲高到10.5元后回落到10.3元，触发止损

### 🛡 策略4：总体亏损止损（纪律底线）

**适用场景**：最后的风险防线

**原理**：持续监控总体浮亏，当浮亏超过止损线时立即执行

**参数配置**：

亏损止损线：浮亏超过此比例时立即止损（如-5%）

**示例**：成本价10元，价格跌到9.5元（浮亏5%），立即止损

## 📝 使用教程

### 方式一：GUI可视化操作（推荐新手）

# 启动GUI应用
python gui_app/main_window.py

**操作步骤**：

1️⃣ 进入"条件单"标签页 2️⃣ 选择"高级止盈止损策略" 3️⃣ 点击快捷预设按钮（如"中长线稳健"） 4️⃣ 根据需要手动微调参数 5️⃣ 输入股票代码和成本价 6️⃣ 勾选要启用的策略 7️⃣ 点击"创建条件单"

系统会自动监控，触发后自动执行交易委托！

```python

```
# 创建管理器
```python
manager = StopLossConditionOrderManager()
```
