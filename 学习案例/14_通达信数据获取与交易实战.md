## 🚀 三、快速开始

### 3.1 第一个量化程序

让我们从最简单的例子开始——获取股票列表：

```python
from tqcenter import tq

```
# 初始化连接
```python
tq.initialize('my_strategy.py')

```
# 获取所有A股列表
```python
stocks = tq.get_stock_list('5') # '5'表示所有A股
print(f"共获取 {len(stocks)} 只股票")
print(f"前5只: {stocks[:5]}")

```
# 关闭连接
```python
tq.close()

```
**输出：**

共获取 5481 只股票
前5只: ['000001.SZ', '000002.SZ', '000004.SZ', '000006.SZ', '000007.SZ']

data = tq.get_market_data(

```python
minute_data = tq.get_market_data(

 count=100
)

```
# 获取实时行情
```python
report = tq.get_report_data('600519.SH')
print(report)

```
### 4.2 实时行情订阅

# 定义回调函数
```python
def on_data_update(data_str):
 print(f"收到行情更新: {data_str}")

```
# 订阅实时行情
```python
tq.subscribe_hq(
 stock_list=['600519.SH'],
 callback=on_data_update
)

```
# 查询订阅列表
```python
subscribed = tq.get_subscribe_hq_stock_list()
print(f"当前订阅: {subscribed}")

```
### 4.3 板块数据

# 获取板块列表
```python
sectors = tq.get_sector_list()
print(f"共 {len(sectors)} 个板块")

```
# 获取某个板块的成分股
```python
stocks = tq.get_stock_list_in_sector('有色金属')

```
## 🔍 五、实战技巧

### 5.1 数据缓存

通达信提供了缓存机制，可以大幅提升数据读取速度：

# 缓存历史K线数据
```python
tq.refresh_kline(
 stock_list=['600519.SH', '000001.SZ'],
 period='1d'
)

```
# 后续查询会从缓存读取，速度提升10倍以上

### 5.2 批量处理

# 一次性获取多只股票数据
```python
stocks = ['600519.SH', '000001.SZ', '600000.SH', '000002.SZ', '601398.SH']

data = tq.get_market_data(
 field_list=['Close', 'Volume'],
 stock_list=stocks, # 批量获取
 period='1d',
 count=100
)

```
### 5.3 错误处理

```python
try:
 data = tq.get_market_data(
 stock_list=['600519.SH'],
 period='1d',
 count=10
 )
 if data and'Close'in data:
 print("数据获取成功")
 print(data['Close'])
 else:
 print("数据为空")
except Exception as e:
 print(f"获取数据失败: {e}")
finally:
 tq.close()

```
