TPythClient.dll 接口及 tqcenter.py 模块完整API文档

本文档详细描述了通达信量化交易系统中TPythClient.dll接口及其上层封装tqcenter.py模块的功能实现情况

一、概述 #

1.1 项目结构

  • TPythClient.dll: 通达信提供的原生DLL接口库
  • tqcenter.py: 对TPythClient.dll的Python封装，提供面向对象的接口

1.2 核心功能

tqcenter.py模块主要提供以下几类功能：

  1. 市场数据获取（K线、Tick数据等）
  2. 财务数据获取
  3. 板块数据获取
  4. 实时行情数据获取
  5. 交易下单接口
  6. 连接池管理

二、已实现功能详解 #

2.1 市场数据获取 已实现

get_market_data() - 获取市场数据

功能描述: 获取股票的K线数据、分钟线数据、Tick数据等

@classmethod
def get_market_data(cls,
                    field_list: List[str] = [],
                    stock_list: List[str] = [],
                    period: str = '',
                    start_time: str = '',
                    end_time: str = '',
                    count: int = -1,
                    dividend_type: Optional[str] = None,
                    fill_data: bool = True) -> Dict

参数说明

参数名 类型 必填 说明
field_list List[str] 否 要获取的字段列表，如['Open', 'High', 'Low', 'Close', 'Volume']
stock_list List[str] 是 股票代码列表，如['600519.SH', '000001.SZ']
period str 是 数据周期，支持'1d','1w','1mon','1m','5m','15m','30m','60m','tick'等
start_time str 否 起始时间，格式YYYYMMDD或YYYYMMDDHHMMSS
end_time str 否 结束时间，格式YYYYMMDD或YYYYMMDDHHMMSS
count int 否 数据条数，-1表示不限制
dividend_type str 否 除权类型：'none'(不复权)、'front'(前复权)、'back'(后复权)
fill_data bool 否 是否填充缺失数据，默认True

返回值: Dict类型，包含各字段的DataFrame数据

使用示例

# 获取日线数据
data = tdxdata.get_market_data(
    field_list=['Open', 'High', 'Low', 'Close', 'Volume'],
    stock_list=['600519.SH'],
    period='1d',
    count=30
)

# 获取分钟线数据
data = tdxdata.get_market_data(
    field_list=['Close', 'Volume'],
    stock_list=['600519.SH'],
    period='5m',
    start_time='20241201',
    end_time='20241231'
)

price_df() - 提取价格数据

功能描述: 从get_market_data返回的数据中提取特定字段并格式化

@staticmethod
def price_df(df, price_col, column_names=None)

参数说明

参数名 类型 必填 说明
df Dict 是 get_market_data返回的数据
price_col str 是 要提取的字段名，如'Close'
column_names List[str] 否 自定义列名

返回值: DataFrame格式的价格数据

2.2 财务数据获取 部分实现

get_financial_data() - 获取财务数据

功能描述: 获取股票的财务报表数据（部分实现，存在权限或配置问题）

@classmethod
def get_financial_data(cls,
                        stock_list: List[str] = [], 
                        table_list: List[str] = [], 
                        start_time: str = '', 
                        end_time: str = '', 
                        report_type: str = 'report_time') -> Dict

参数说明

参数名 类型 必填 说明
stock_list List[str] 是 股票代码列表
table_list List[str] 否 财务表列表，空列表表示获取所有表
start_time str 否 起始时间
end_time str 否 结束时间
report_type str 否 报告类型，默认'report_time'

返回值: Dict类型，包含各股票的财务数据

重要提醒: 经测试发现，此接口存在以下问题：

  • 函数接口已完整实现，可正常调用
  • 但实际返回空数据（包含0个财务表）
  • 根据测试结果，返回错误代码6（数量错误）
  • 可能需要特殊的财务数据权限或配置才能正常使用
  • 建议使用第三方数据源（如Tushare）作为替代方案

理论上应支持获取以下财务报表数据：

  • 资产负债表
  • 利润表
  • 现金流量表
  • 各类财务指标数据

使用示例

financial_data = tdxdata.get_financial_data(
    stock_list=['600519.SH'],
    start_time='20230101',
    end_time='20231231'
)

2.5 交易下单接口 部分实现

order_stock() - 下单接口

功能描述: 发送交易订单（部分实现，存在参数转换问题）

@classmethod
def order_stock(cls,
                account:str, 
                stock_code:str, 
                order_type:int, 
                order_volume:int, 
                price_type:int, 
                price:float, 
                strategy_name:str, 
                order_remark: str = '')

参数说明

参数名 类型 必填 说明
account str 是 交易账户
stock_code str 是 股票代码
order_type int 是 订单类型
order_volume int 是 订单数量
price_type int 是 价格类型
price float 是 订单价格
strategy_name str 是 策略名称
order_remark str 否 订单备注

返回值: Dict类型，包含下单结果

重要提醒: 经测试发现，此接口存在参数转换问题，无法正常调用。具体表现为：

  • 函数签名中声明了8个参数，但DLL调用时只有7个参数
  • 存在类型转换错误：TypeError: Don't know how to convert parameter 7
  • 根据测试报告，此功能未进行实际下单测试
  • 可能需要特殊的交易权限或配置才能正常使用

建议在修复参数问题后再进行实际交易测试。

六、使用注意事项 #

6.1 初始化要求

  1. 使用前必须调用tdxdata.initialize(__file__)初始化连接
  2. 使用完毕后应调用tdxdata.close()关闭连接
  3. 确保TPythClient.dll文件在正确路径下

6.2 数据格式说明

  1. 股票代码格式：6位数字+.市场后缀（如600519.SH）
  2. 时间格式：YYYYMMDD或YYYYMMDDHHMMSS
  3. 除权类型：'none'（不复权）、'front'（前复权）、'back'（后复权）

6.3 异常处理

  1. 网络异常可能导致数据获取失败
  2. 数据量过大时可能出现超时
  3. 股票代码格式错误会导致函数返回错误信息

6.4 性能优化建议

  1. 合理使用count参数避免获取过多数据
  2. 批量获取多只股票数据以减少网络请求
  3. 使用缓存机制避免重复获取相同数据

七、常见问题及解决方案 #

7.1 数据获取失败

问题现象: get_market_data返回空数据或错误信息

解决方案:

  1. 检查股票代码格式是否正确
  2. 确认时间范围是否合理
  3. 检查网络连接是否正常
  4. 验证DLL文件是否正确加载

7.2 连接初始化失败

问题现象: initialize()函数抛出异常

解决方案:

  1. 确认TPythClient.dll文件存在且路径正确
  2. 检查通达信客户端是否正常运行
  3. 验证权限设置是否正确

7.3 内存泄漏问题

问题现象: 长时间运行后内存占用持续增长

解决方案:

  1. 确保每次使用完后调用close()方法
  2. 合理使用连接池管理
  3. 避免大量数据缓存在内存中
