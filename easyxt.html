EasyXT

基于 MiniQMT 平台中的 xtquant 进行二次封装，提供统一接口、智能参数处理与完善的错误机制，让量化数据获取与交易更简单、更稳健。

功能亮点 安装配置 快速上手 常用API 架构设计
项目简介
位置：EasyXT 项目 适配语言：Python 3.9 ~ 3.12 场景：数据获取 / 交易执行 / 策略回测
  • 统一 API：对 xtquant 的多模块进行统一命名与参数风格封装。
  • 智能参数：容错与默认值注入，减少样板代码。
  • 错误处理：分级异常与重试机制，保障线上稳定性。
  • 开发友好：更友好的返回结构与类型提示。
功能亮点
  • 行情数据：K线/分时/快照等统一接口，支持多数据源降级。
  • 账户交易：下单、撤单、查询统一封装，支持风控钩子。
  • 数据管理：内置 DuckDB 支持，本地数据秒级响应。
  • 智能降级：QMT → TDX → 东方财富三级数据源自动切换。
  • 配置管理：.env 文件统一管理，支持多账户配置。
安装与环境配置
# 1. 克隆项目 git clone https://github.com/quant-king299/EasyXT.git cd EasyXT # 2. 安装依赖 pip install -r requirements.txt # 3. 配置 .env 文件 # 在项目根目录创建 .env 文件，填入以下内容： # ===== 必须配置 ===== # 数据目录（必须） STOCK_DATA_ROOT=D:/StockData DUCKDB_PATH=D:/StockData/stock_data.ddb # QMT 配置（实盘必须） QMT_DATA_DIR=D:/国金QMT交易端模拟\userdata_mini QMT_ACCOUNT_ID=你的QMT账户ID QMT_EXE_PATH=D:/国金QMT交易端模拟\bin.x64\XtMiniQmt.exe QMT_PASSWORD=你的QMT密码 # Tushare（可选，回测和因子分析用） # 建议充值到 2000 积分以上：https://tushare.pro/weborder/#/login?reg=344724 TUSHARE_TOKEN=你的TushareToken # 4. 启动 QMT/miniQMT 并登录
快速上手：三步获取数据
from easy_xt import get_api # 1) 初始化 API（自动读取 .env 配置） api = get_api() api.init_data() # 2) 获取行情数据（支持多数据源自动降级） df = api.get_price( stock_code='600000.SH', period='1d', start_date='20240101', end_date='20240618' ) print(df.head()) # 3) 交易功能（需要先初始化交易服务） api.init_trade( qmt_path='D:/国金QMT交易端模拟', session_id='my_strategy' ) api.add_account('你的账户ID', 'STOCK') # 下单 result = api.trade.buy( account_id='你的账户ID', code='600000.SH', volume=100, price=10.5 ) print(result)
常用 API 一览

行情数据

  • get_price(code, period, start_date, end_date)
  • get_quote(code) - 实时行情快照
  • get_ticks(code, start_date, end_date)
  • subscribe(codes, on_update) - 订阅实时数据

账户交易

  • init_trade(qmt_path, session_id)
  • add_account(account_id, account_type)
  • trade.buy(account_id, code, volume, price)
  • trade.sell(account_id, code, volume, price)
  • trade.cancel(account_id, order_id)
  • trade.get_positions(account_id)
  • trade.get_orders(account_id)
  • trade.get_balance(account_id)

数据管理

  • DuckDB 本地数据库支持
  • get_stock_list() - 获取全市场股票列表
  • get_convertible_bonds() - 获取可转债列表
  • get_etf_list() - 获取 ETF 列表

工具函数

  • normalize_code(code) - 代码格式化
  • format_datetime(dt) - 时间格式化
  • retry(func, times=3) - 重试装饰器
架构示意
EasyXT ├─ API 层 (api.py) │ ├─ get_price() - 统一行情接口 │ ├─ init_trade() - 交易初始化 │ └─ trade - 交易操作封装 │ ├─ 数据源 (realtime_data/) │ ├─ qmt_provider.py - QMT/miniQMT 数据源 │ ├─ tdx_provider.py - 通达信 TDX 数据源 │ └─ eastmoney_provider.py - 东方财富数据源 │ ├─ 数据管理 (data_manager/) │ ├─ duckdb_manager.py - DuckDB 管理 │ ├─ hybrid_manager.py - 混合数据源管理 │ └─ unified_duckdb_manager.py - 统一 DuckDB 接口 │ ├─ 交易封装 (core/trade/) │ ├─ qmt_trade_api.py - QMT 交易 API │ └─ trade_executor.py - 交易执行器 │ └─ 工具函数 (utils/) ├─ code_utils.py - 代码处理工具 └─ date_utils.py - 日期处理工具
数据源降级策略
优先级顺序（自动切换）: 1. DuckDB (本地数据) ⚡⚡⚡⚡⚡ └─ 秒级响应，适用于回测和历史数据查询 2. QMT/miniQMT ⚡⚡⚡⚡ └─ 实时行情，适用于实盘交易场景 └─ 支持订阅推送 3. 通达信 TDX ⚡⚡⚡ └─ 备用数据源，在线数据查询 4. 东方财富 ⚡⚡ └─ 兜底数据源，可能会限流 使用示例: # 自动降级获取数据（推荐） api = get_api() api.init_data() df = api.get_price('600000.SH', period='1d', count=10) # 如果 QMT 不可用，自动降级到 TDX 或东方财富

常见问题
  • Q: 如何获取 QMT 账户？
    A: 需要在券商处开通 QMT/miniQMT 量化交易权限，登录后即可看到账户 ID。
  • Q: 支持哪些券商？
    A: 支持提供 QMT/miniQMT 的券商，如国金证券、国盛证券等。
  • Q: 如何获取 Tushare Token？
    A: 访问 https://tushare.pro/weborder/#/login?reg=344724 注册并充值到 2000 积分以上。
  • Q: 可以同时运行多个策略吗？
    A: 可以，每个策略使用不同的 session_id 即可。
